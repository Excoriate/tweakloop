# ADR-012 — No CRDT, cloud sync or plugin runtime in v0.1

## Status

Accepted

## Context

The first release must build one coherent loop — immutable revisions, typed intent, durable work, evidence, decisions — before expanding horizontally. Collaborative editing, cloud accounts, and plugin ecosystems each carry large, independent complexity budgets and none repair the semantic and execution gaps that define the product.

## Decision

v0.1 explicitly excludes: CRDTs (Tweakloop is not a concurrent text editor — the core concurrency problem is competing immutable revisions and intents, not simultaneous character insertion; branching in the revision graph represents concurrency honestly); cloud synchronization and collaborative accounts; an arbitrary plugin runtime (artifact adapters use an internal registry until at least two independently implemented external adapters demonstrate the required abstraction); WYSIWYG web design; PowerPoint and template galleries; public hosting; enterprise permissions.

## Alternatives rejected

- CRDT-based collaborative editing in the core.
- A third-party plugin API before the adapter abstraction is proven twice.
- Hosted/cloud-first delivery before the local loop works.

## Consequences

Some user requests are deferred by design. Scope stays testable against the v0.1 vertical slice. Concurrent agent output is preserved as branches, not merged text. The internal adapter protocol (`detect` / `ingest` / `index` / `diff`) is the future extension seam.

## Falsifier

Dominant, sustained demand for real-time co-editing or hosted collaboration from the actual user base — not hypothetical markets.

## Migration path

Each exclusion is revisited as its own ADR when evidence arrives; the event log and protocol schemas are the stable substrate any of them would build on.
