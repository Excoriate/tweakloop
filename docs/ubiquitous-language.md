# Tweakloop ubiquitous language

The shared vocabulary for code, documents, tests, and conversation. Terms mean exactly this — in the domain model, in projections, and in the UI. Where a term is often confused with a nearby concept, the entry says what it is **not**. Grounded in [docs/architecture/](architecture/), especially the information model ([03-information-model.md](architecture/03-information-model.md)).

## Artifact and identity

- **Project** — the logical product shared across clones and worktrees, identified by `project_id` in `.tweakloop/project.json` (committed, non-secret). Not a directory: two clones of one repository are one project.

- **Workspace** — one local worktree or directory instance, identified by `workspace_id` and holding local authority (daemon, fact log, object store) under an OS state directory. Not the repository itself, and not shared between worktrees.

- **Artifact** — the stable logical identity of a reviewable thing (`artifact_id`). Not a file: a source file is merely one way to produce a revision, files move, and multiple artifacts may derive from one source.

- **Revision** — one immutable snapshot in an artifact's history (`revision_id`): entry document, referenced assets, semantic index, producer metadata, parent revisions, content hashes, optional Git context. Not "the latest version" — latest is a projection. A revision's bytes never change.

- **Revision manifest** — the generated, `$schema`-tagged description of a revision (files, hashes, parents, producer, source, Git context). Generated by the CLI, not hand-authored by agents.

- **Content hash** — SHA-256 identity of exact bytes in the object store. Not semantic identity: it changes precisely when content changes.

- **Semantic node** — a stable addressable concept within a revision (an architecture component, a plan phase), described in the semantic index with text and structure digests. Not a DOM element; the element is where the node happens to render.

- **Semantic ID** — the durable name of a semantic node (`data-tweak-id`, e.g. `architecture.data-storage`). Describes meaning, never presentation (`left-card-3` is invalid).

- **Anchor** — the recorded set of independent clues locating an intent's target: revision ID, semantic ID, source reference with line ranges, text quote with context, DOM hint, and anchor strength. Not a CSS selector; selectors are hints, never identity.

- **Orphaned anchor** — an anchor whose target could not be re-established against a newer revision after the full re-anchoring order. Recorded as the explicit fact `artifact.anchor-orphaned`; never silently retargeted.

## Review and intent

- **Review batch** — the human's deliberate submission boundary: accumulated drafts committed in one transaction (`review.batch-submitted` plus intent events plus work-item creation). Not tied to agent presence.

- **Draft** — ephemeral, crash-resilient working state (`review_drafts` table) before submission. Not history; submitting converts drafts into immutable intent facts.

- **Intent** — one typed, immutable human request, question, constraint, or decision (`replace-text`, `add-constraint`, `approve-node`, ...; free-form `comment` is the fallback). Not editable: to change your mind, supersede it (`intent.superseded`). Not a status container — its dimensions live in separate facts.

- **Approval** — a fact binding a semantic node's content digest at a specific revision. Not a promise about future revisions: later changes render the approval invalidated in projections, never mutated or auto-transferred.

## Work and execution

- **Work item** — the unit offered to agents (`work_id`): intent IDs, the base revision the human reviewed, dependencies, expected verification. Not a task in an internal executor — Tweakloop offers work; harnesses execute it.

- **Claim** — durable temporary ownership of a work item by an agent (`work.claimed`, carrying a `claim_id`). Completion requires the claim ID; a stale claim's completion is rejected.

- **Lease** — the ephemeral liveness record backing a claim (`runtime_leases`: process nonce, expiry, last heartbeat). Not history: heartbeats renew the lease row, never append events. Expiry makes work claimable again and surfaces `work.abandoned`.

- **Agent** — any external actor able to invoke the CLI and parse versioned output. Not a built-in integration: the core has no Claude Code/Codex/OpenCode code paths. Not identified by PID.

- **Actor** — the recorded identity behind a command (`kind` human/agent/system, `id`, optional `runId`). Every durable mutation names its actor.

- **Result** — the agent's immutable account of what it changed: addressed intents, new revision IDs, repository paths, limitations, remaining uncertainty. Not proof — see Evidence.

## Evidence and decision

- **Evidence** — immutable, content-addressed proof attached to a result or verification: command runs with exit codes and output hashes, Git diffs, screenshots, plan output, policy results, bounded agent rationale, manual observation. Not agent prose alone, and never modified — superseded by corrected evidence.

- **Verification** — the recorded evaluation of specified evidence against an expectation. Not human acceptance: tests can pass and the human still reject; verification can fail and the human accept a draft. Missing evidence is never interpreted as passing.

- **Decision** — the human's recorded acceptance, rejection, approval, or reopening. The only authority that closes the loop.

## Machinery

- **Event** — one immutable durable fact in the append-only log, ordered by database `seq` (compact vocabulary: `intent.created`, `work.claimed`, `decision.accepted`, ...). Not UI telemetry: cursor moves, hovers, heartbeats, and presence never become events.

- **Command** — a requested durable mutation. Not an event: commands can be rejected; events are facts that happened.

- **Command envelope** — the single versioned wrapper (`tweakloop.command/v1`) every command travels in: `commandId`, `idempotencyKey`, `workspaceId`, `actor`, `type`, `expected.streamVersion`, schema-validated payload.

- **Idempotency key** — the caller-chosen key that makes retries safe: a repeated key returns the original receipt and produces no duplicate effects.

- **Stream / stream version** — the per-entity event sequence (e.g. one artifact's events) and its monotonically increasing version, used for optimistic concurrency via `expected.streamVersion`.

- **Projection** — a derived, disposable read model (`p_*` tables) produced by deterministic reducers over ordered events. Not truth: rebuildable at any time from the log (`tweak repair --rebuild-projections`).

- **Transactor** — the daemon's single serialized writer: validates the envelope, checks idempotency, calls the pure `decide`, appends events, updates synchronous projections, records the receipt, commits, then publishes. Nothing else writes to SQLite.

- **Daemon** — the one-per-workspace process owning the write connection, event sequence, watchers, claims, and both HTTP listeners. Not a fixed-port service: ports are OS-assigned, loopback only, discovered via the runtime descriptor.

- **Runtime descriptor** — the ephemeral `runtime.json` (PID, ports, process nonce, protocol version) used to discover a live daemon. A locator, never authoritative state.

- **Shell origin** — the trusted browser origin: review UI, command API, authentication, SSE stream.

- **Artifact origin** — the isolated browser origin serving read-only immutable revision files and the bridge script. No mutation routes, no shell cookie.

- **Bridge** — the versioned script running inside the artifact iframe, communicating with the shell over a transferred `MessageChannel` port after an exact-origin handshake. It reports selections and semantic metadata; it cannot mutate daemon state, read repository files, or receive shell credentials.

- **Adapter** — an internal implementation of `detect` / `ingest` / `index` / `diff` for one artifact kind (HTML, Markdown). Not a third-party plugin API — that waits until two independent external adapters prove the abstraction.
