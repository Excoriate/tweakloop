Azure Platform Architecture

Network

Hub-and-spoke topology. Ingress is private only, through the internal Application Gateway. Spokes host workload subnets with NSGs per tier.

Data Platform

Azure PostgreSQL Flexible Server with TimescaleDB for telemetry. Cold data tiers to ADLS after 90 days.

Identity

Managed identities for all workloads; Entra ID groups with PIM for human access. No client secrets anywhere in configuration.
