# Markdown collaboration in Tweakloop {#markdown-collaboration}

This document is canonical Markdown. Tweakloop renders it as a safe review projection while comments, chat, work, and revisions remain durable workspace facts.

## Dynamic TaskBar {#taskbar}

The selected comment and the agent's current work stay visible together. Drafts, comments, tasks, and chat remain reachable without turning the rail into a dashboard.

### Review loop

1. Select an anchored heading or paragraph.
2. Leave a comment for the session agent.
3. Follow the resulting work in the Dynamic TaskBar.
4. Publish a revised Markdown file without mutating the previous revision.

## Whiteboard {#whiteboard}

An independent canvas and an embedded canvas should participate in the same revision, comment, task, and chat model as this document.

## Safety check {#safety}

Raw HTML is displayed as inert source rather than receiving script execution inside the artifact origin.
